POLADENT SISTEMA — FASE 19
USUARIOS CON CORREO Y CONTRASEÑA INDIVIDUAL

Implementado:
- Cada usuario administrativo puede tener su propio correo y contraseña.
- El rol determina qué módulos puede ver y abrir.
- Creación de acceso desde Roles y permisos.
- Firebase crea la cuenta mediante una instancia secundaria para no cerrar la sesión del administrador actual.
- Se envía correo para que el usuario establezca/cambie su propia contraseña.
- Poladent no muestra ni guarda la contraseña personal.
- Botón “Olvidé mi contraseña” en el login.
- Acceso desactivable sin borrar cuenta ni historial.
- Auditoría de creación, activación y desactivación de usuarios.
- Usuarios y auditoría incluidos en respaldo.
- El login valida estado/rol antes de mostrar el panel.
- Los funcionarios que solo marcan asistencia siguen usando PIN.
- firebase/config.js no fue modificado.

NOTA:
El envío de correos depende de Firebase Authentication y de que el dominio usado por GitHub Pages esté autorizado en Firebase.
